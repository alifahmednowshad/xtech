# 🚀 XTech - Innovative IT Solution Company

Welcome to the official repository for **XTech**, a modern, responsive, and feature-packed website designed for IT solution providers, tech agencies, and corporate businesses.

---

## 📸 Overview & Preview

**XTech** is a professional agency template/website designed to display services, company information, client reviews, and team members, helping businesses establish a strong online presence.

---

## 🛠 Tech Stack

The core technologies used in this project are:

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Framework / Styling:** Bootstrap 5 / Tailwind CSS
* **Icons & Fonts:** FontAwesome / Google Fonts
* **Deployment:** Netlify

---

## ✨ Key Features

* 🌐 **Fully Responsive:** Smooth layout across desktop, tablet, and mobile devices.
* 🖥️ **Modern Hero Section:** Bold typography, CTA buttons, and immersive visual background.
* 📋 **Multi-Section Layout:**
  * **Home:** Main banner and call to action
  * **About Us:** Detailed company insights
  * **Why Us:** Key highlights and competitive advantages
  * **Services:** Interactive service list
  * **Reviews:** Client feedback and testimonials
  * **Team:** Member profiles
* 📞 **Contact Section:** Direct reach-out options for clients.

## 💻 Local Setup & Installation Guidelines

Follow these steps to run this project locally on your machine:

### Prerequisites

* A modern web browser (e.g., Chrome, Edge, Firefox)
* [Git](https://git-scm.com/) installed on your computer
* [Node.js](https://nodejs.org/) *(Optional, if using npm packages/live-server)*

### Step-by-Step Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/alifahmednowshad/xtech.git
   ```

2. **Navigate to Project Folder:**
   ```bash
   cd xtech-website
   ```

3. **Install Dependencies (If applicable):**
   ```bash
   npm install
   ```

4. **Run the Project:**
   * **Option A (Direct):** Open `index.html` in your browser.
   * **Option B (Live Server):**
     ```bash
     npm start
     ```
